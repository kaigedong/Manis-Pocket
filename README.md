# Manis Pocket

复制过的，随手找回。

Manis Pocket 是轻量的剪贴板历史工具，支持快速搜索、固定常用内容，以及在 macOS 与 Linux Wayland 设备之间通过本地网络同步文本剪贴板。Android 版本仍在开发中。

下载见[发布列表](https://github.com/kaigedong/Manis-Pocket/releases)。
