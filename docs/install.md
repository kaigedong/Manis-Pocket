# 安装

macOS（Apple Silicon，macOS 14 或更新版本）在[发布列表](https://github.com/kaigedong/Manis-Pocket/releases)中选择最新的版本化发布，下载其中的 `ManisPocket.app.zip`，解压后将 `ManisPocket.app` 移到“应用程序”。

每次发布保留独立版本和安装包，不再覆盖 `latest-beta`。当前测试版采用临时签名，尚未经过 Apple 公证；如果 macOS 阻止首次打开，先尝试打开一次，再按 [Apple 的说明](https://support.apple.com/zh-cn/102445)在“系统设置 → 隐私与安全性”中选择“仍要打开”。

Arch Linux 安装 `manis-pocket-bin`（见 [AUR 二进制包](../packaging/aur/README.md)），或使用[本地 PKGBUILD](../packaging/archlinux/README.md) 从仓库构建。
